# Solgys Apps — site public

Site GitHub Pages destiné aux pages publiques des applications Solgys Apps.

## MonPV

- Assistance : <https://solgys-apps.github.io/monpv/>
- Politique de confidentialité : <https://solgys-apps.github.io/monpv/privacy>

La racine du dépôt sert de page d’accueil universelle. Chaque application dispose de son propre dossier afin de pouvoir ajouter ensuite BET OUT, Prix Péage et les futures applications sans modifier les URL de MonPV.

## Publication

Le dépôt doit être publié sous le nom `solgys-apps.github.io` dans le compte ou l’organisation GitHub `solgys-apps`, avec GitHub Pages configuré sur la branche `main` et le dossier racine.

La page de confidentialité est stockée dans `monpv/privacy/index.html`. L’adresse `/monpv/privacy` aboutit à `/monpv/privacy/` : le slash final est normal, et aucune extension `.html` n’est nécessaire. Les liens internes utilisent la variante avec slash.

Le fichier racine `privacy.html` est un alias local du nouveau site. Il ne redirige pas à lui seul l’ancien domaine `6zvn2cftk9-bit.github.io` : l’ancien dépôt doit rester en place et recevoir ses propres redirections, seulement après vérification du nouveau site.

Le contenu des rubriques d’assistance et de confidentialité est conservé. Ce changement d’adresse n’est pas un nouvel audit juridique ou une vérification du code iOS.
