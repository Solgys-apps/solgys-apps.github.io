Comment pouvons-nous vous aider ?

Retrouvez ici les réponses aux questions fréquentes concernant le scan, les échéances, les notifications et vos PV enregistrés.

Scanner un avis de contravention

Depuis l’accueil, touchez Scanner mon PV, photographiez lisiblement votre avis puis vérifiez toujours les informations détectées avant de l’ajouter à MonPV.

Une information détectée est incorrecte

Avant l’enregistrement, utilisez Modifier pour corriger les informations disponibles. Le document officiel reste la référence en cas de différence avec les données affichées dans l’application.

Notifications d’échéance

Dans Réglages → Notifications, vous pouvez activer ou désactiver les rappels 7 jours avant, 3 jours avant et la veille de l’échéance. Les notifications concernent uniquement les PV enregistrés dans MonPV.

Paiement et contestation

MonPV vous redirige vers les services officiels lorsque vous choisissez de payer ou de contester. MonPV n’encaisse aucun paiement et ne traite aucune contestation.

Supprimer les publicités

L’option MonPV sans publicité est un achat unique. Si vous l’avez déjà acheté avec le même compte Apple, utilisez Restaurer mes achats dans les Réglages.

Nous contacter

Pour une question, un problème ou une suggestion, vous pouvez écrire directement à solgys.apps@gmail.com.

Vous pouvez également ouvrir MonPV → Réglages → Aide & contact depuis l’application.
